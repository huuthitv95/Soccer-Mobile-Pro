# Pre-publication audit — 2026-09-26

Scope: both working trees and the recovery commits being integrated into main, Unity compile/asset validation, offline milestone behavior, source tools, evidence integrity, repository hygiene and branch ancestry. This is not an Android release, restored-gameplay, or exhaustive security assessment.

## Findings addressed

- APK ignore rule `**/build/` hid original source metadata under `app/src/main/META-INF/com/android/build/gradle/`. Scope the rule to root/app build outputs and include the metadata file.
- PNG verification accepted a truncated file with only the correct signature. The validator now decodes the image; regression fixtures cover a truncated signature and a valid image. Pipeline checks: **41 passed**, plus six exclusive-mode pairs and existing-output refusal.
- Redirecting GlobalConfigAudit intermediates outside the repo exposed IDE-regenerated local `obj` sources, causing duplicate assembly attributes. Explicitly exclude `bin/**` and `obj/**`; the redirected .NET build now passes with zero warnings/errors.
- Both repos now carry AGENTS.md recording the user's main-only workflow. This publication closes existing recovery branches; subsequent work must remain on main unless the user requests otherwise.
- Git whitespace policy recognizes Unity-generated empty YAML scalars in `.meta` files. Their serialized bytes and GUIDs are preserved; source-code whitespace checks remain enabled.

## Cleanup

The cleanup manifest covers 80 generated files / 2,421,855 bytes (2.31 MiB): Unity Logs; APK .gradle and root build output; GlobalConfigAudit bin/obj. Recursive deletion was blocked by automatic policy review, so these directories were moved reversibly to `Soccer-Unity-Recovery/Runs/AuditPublish-20260926-main/GeneratedArchive`. Workspace clutter was removed; this did **not** reclaim disk space. IDEs may regenerate ignored build files.

Library, generated Unity solution/projects, IDE/UserSettings, original assets/APK, AuxiliaryFiles, tracked evidence and all existing recovery backups/reports are retained. No blanket git clean or history rewrite was used. All move sources and destinations were checked for workspace containment/reparse points; no active build/Editor referenced the cleanup targets.
